GranPhone

A phone your grandmother can actually use.
Big buttons. No ads. No accounts. Free & open source.

Download APK

What it is

  • One screen, huge tiles — Phone, Contacts, SOS, Messages, Photos, Alarms, Flashlight
  • Real dialer built in — giant keypad and an oversized incoming-call screen
  • SOS button — one tap calls a family member
  • Kiosk mode — lock the phone to the essentials, PIN to exit
  • Runs on old phones — Android 6+, 1 GB RAM, fully offline
  • Nothing to betray them — no ads, no accounts, no telemetry, auditable code

Install

1. Download the APK from Releases

2. On the phone: press HOME → pick GranPhone → Always

3. Set GranPhone as the default Phone app for the big-button call screen

Full guide incl. kiosk mode: docs/INSTALL.md (English + Русский)
