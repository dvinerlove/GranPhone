# Plan — atomic questions

- Q1: Competitor senior launchers — what UX patterns do BIG Launcher, Grand
  Launcher, Simple Phone, Senior Safety Phone, EasyPhone use? Strengths/weaknesses,
  what reviewers/users praise and complain about.
- Q2: Elderly/novice UX guidelines — tap target sizes, typography size/contrast
  for low vision, cognitive load, error prevention, confirmation patterns.
  Sources: WCAG, NIA senior-friendly guidelines, academic/a11y research.
- Q3: OS-level "simple modes" — iOS Assistive Access, Samsung Easy Mode, Xiaomi
  Lite/Easy mode, Google Pixel / Android accessibility suite — what patterns do
  platform vendors use for seniors?
- Q4: Modern Android design system — Material 3 / Material You current guidance,
  dynamic vs fixed color, design tokens, large-font support, edge-to-edge,
  status bar handling on old Android versions; Compose vs Views for accessibility
  apps; Material Components library capabilities on minSdk 21.
- Q5: Iconography & visual language for seniors — icon+label vs icon-only,
  pictogram style guidance, color semantics (red=hang up etc.), avoiding
  ambiguous icons.

Coverage matrix lives in coverage.md.
