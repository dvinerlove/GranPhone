## Key verbatim quotes

1. Memory limits: "People with impaired working memory may only be able to hold one to three items in their memory at the same time." ; "They may have trouble or be unable to remember new icons and interface paradigms."
2. Min steps: "I need to get to the feature I need using the minimum number of easy steps."
3. Undo vs confirm: "I need to go back to where I was in one simple step, when I touch the wrong control." ; "I need predictable back or undo features so that I know exactly where I was previously, before I made a mistake."
4. Pattern "Go back and return": "Always let the user return to a previous point." ; technique list includes "Using back and undo features without unwanted data loss."
5. Pattern "Make it Easy to Undo Form Errors": "Always allow the user to check their work and correct any mistakes. Once the user has fixed their mistake it should be easy to get back to the place they were at without redoing additional steps."
6. Consistency: "I need the controls to be consistently positioned on the screen where I expect them to be." ; "Use familiar design patterns, terms, and icons ... Ensure the look, location, and interaction of controls and other elements are familiar and consistent across the site."
7. Context recovery: "If the user does get distracted, headings and breadcrumbs can help orientate the user ... Providing linked breadcrumbs can help the user undo mistakes."
8. Aging note: "some people with age related forgetfulness ... may also require higher contrast."

## Notes
- Directly addresses Q2's cognitive-load ask: minimize steps, never rely on memory across steps, undo > confirmation dialogs (recover rather than block), persistent consistent control positions, explicit current-location indicators.
- Frames seniors via "age related forgetfulness" persona — normal aging = slower learning, occasional word/step loss.
