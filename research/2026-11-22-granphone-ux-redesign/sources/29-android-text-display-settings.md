# Source 29 — Change text & display settings (Android Accessibility Help)

- URL: https://support.google.com/accessibility/android/answer/6006972 (redirects to answer/11183305)
- Publisher: Google — Android Accessibility Help
- Tier: L1 (official platform docs)
- Ownership: vendor-authored

## Key verbatim quotes

- "You can also find accessibility settings in quick settings, where you can quickly change your preferred text and content settings."
- "These settings can also be set up from the start in the setup wizard." (accessibility during first-boot)
- Font size: "move the slider left or right"; "You can adjust font size up to 200%."
- "The font size setting doesn't apply to some apps."
- Display size: separate slider under Settings, independent of font size.
- "You can use bold font to improve visibility" (Settings > Accessibility > Display size and text > Bold text).
- "To use outline text, your device must run Android 16 and up. To make text easier to read on devices that run Android 15 and below, use high-contrast text."
- Color correction with intensity slider: "Red-green (Deuteranomaly)", "Red-green (Protanomaly)", "Blue-yellow (Tritanomaly)", "Grayscale: Remove all color."
- "Color inversion reverses the color on the screen, and applies to everything including media."
- "You can turn off animations to help you focus" (Remove animations).
- Extra dim: "You can dim your screen beyond your phone's minimum brightness so it's more comfortable to read."

## Context
Stock Android has no single "senior mode"; instead granular accessibility levers a launcher can pre-set: font size (≤200%), display size, bold, outline/high-contrast text, color correction/inversion, remove animations, extra dim, Quick Settings font tile, and setup-wizard exposure. No caretaker/locked-mode concept at OS level.
