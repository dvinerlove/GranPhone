## Key verbatim quotes

1. SC 2.5.8 (AA) text: "The size of the target for pointer inputs is at least 24 by 24 CSS pixels, except when: Spacing / Equivalent / Inline / User Agent Control / Essential..."
2. On intent: "Users with dexterity limitations and those who have difficulty with fine motor movement find it difficult to accurately activate small targets when there are other targets that are too close."
3. "Disabilities addressed by this requirement include hand tremors, spasticity, and quadriplegia."
4. Why 24px not bigger: "after reviewing the average target size of various high-traffic sites – the Working Group settled on the smaller measure of 24 by 24 CSS pixels for the '(Minimum)' version of this criterion, while 2.5.5 Target Size (Enhanced) uses the larger 44 by 44 CSS pixel measure as its threshold size."
5. Recommendation: "For important links/controls, consider aiming for the stricter 2.5.5 Target Size (Enhanced)."
6. SC 2.5.5 (AAA) text: "The size of the target for pointer inputs is at least 44 by 44 CSS pixels except when: Equivalent / Inline / User Agent Control / Essential..."

## Notes
- 24×24 CSS px is the floor for AA; 44×44 CSS px is the AAA/"enhanced" level and explicitly the level to aim for on important controls — highly relevant for a senior launcher.
- Exceptions exist for spacing, equivalent controls, inline text, UA defaults, essential presentation.
