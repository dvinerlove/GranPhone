# Source 27 — How to enable/disable the Lite mode on the Xiaomi smartphone?

- Publisher: Xiaomi Global Support (mi.com)
- Tier: L1 (official vendor support page)
- Ownership: vendor-authored
- Fetched: 2026-11-22 via r.jina.ai

## Key verbatim quotes

- "The Xiaomi smartphone supports the Lite mode, making the phone easier to view, understand and operate."
- Enable path: "Navigate to [Settings]; Select [Home screen]; Tap on [Home screen]; Select [Lite mode]"
- "You can also navigate to the Lite mode function by searching it in the search bar on the top of the Settings interface"
- Disable: "please go to [Settings] and tap on [Lite mode is on]. Then tap [Turn off Lite mode]."

## Context
Lite mode is a home-screen style option under Settings > Home screen in current MIUI/HyperOS — a launcher-level setting, not a separate environment. Page is thin on what changes visually; related Xiaomi docs (not fetched) describe enlarged UI elements, more accessible calling, enhanced security. Exit path is deliberately discoverable: a persistent "Lite mode is on" entry appears at top of Settings.
