## Key verbatim quotes

- "If you'd like some assistance with using your Home screen, you can turn on Easy mode. It will enlarge the on-screen items, provide a high contrast keyboard, and help prevent accidental touches when tapping." (section "Use Easy mode")
- "From Settings, tap Display, and then tap Easy mode. Tap the switch to turn it on."

## Context
Easy Mode is a display-level toggle (not a separate account/profile). Three stated effects: enlarged UI items, high-contrast keyboard, accidental-touch prevention (longer touch-and-hold delay). Reversible via the same switch — user keeps all apps/settings, unlike Apple's separate Assistive Access environment.
