## Key verbatim quotes

- "With Assistive Access on iPhone, the Phone and FaceTime apps are combined into a single Calls app."
- "Receive Calls From | Allow the person using Assistive Access to receive calls from anyone, from all contacts in the Contacts app, or from favorite contacts only."
- "Make Calls To | Allow the person using Assistive Access to call anyone, all contacts in the Contacts app, or favorite contacts only."
- "Favorite contacts are shown on the first screen when the Calls app is opened in Assistive Access."
- "Allow the person using Assistive Access to view recent calls or voicemails." (optional recents/voicemail — off by default)
- "To hang up, tap End Call, then tap End Call again to confirm."
- "To answer an incoming call in Assistive Access, tap Answer. If you don't want to take the call, tap Don't Answer, then tap Don't Answer again to confirm."
- "On any screen in Assistive Access, the person using Assistive Access can always tap Back to return to the previous screen."
- In-call options are restrictable: Keypad and Speaker toggles configurable by supporter.
- Emergency call always possible via triple-click side/Home button → Emergency, even when locked.

## Context
Patterns: merge two apps into one task-named app ("Calls"); favorites-first opening screen (photos+names, not numbers); whitelist model for who can call/be called; every destructive/committal action gets an explicit confirm step; persistent Back button; per-feature capability toggles set by the supporter (keypad, speaker, recents, voicemail).
