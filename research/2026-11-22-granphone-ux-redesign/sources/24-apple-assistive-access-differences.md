## Key verbatim quotes

- "Assistive Access apps have been redesigned for cognitive accessibility and include larger text and icons, more focused features, and customizable options."
- "To minimize pop-ups while using iPhone, apps won't ask for permission to access information such as location, photos, and contacts. Instead, you have the option to set access permissions for apps when you set up Assistive Access."
- "You must exit Assistive Access and go to Settings in order to install new software updates, because there is no Settings app or notifications in Assistive Access that indicate whether an update is available."
- "Certain app privacy information, status icons, and symbols aren't available in Assistive Access, including those that indicate network availability, Airplane Mode, Focus, or Bluetooth, or when an app or website is using Location Services."
- "When you set up Calls for Assistive Access, you can choose to allow calls with anyone, all contacts in the Contacts app, or favorite contacts only."
- "Emergency SOS via satellite isn't available in Assistive Access"; all other automatic emergency dialing also unavailable.

## Context
Documents what Assistive Access REMOVES: permission pop-ups (pre-granted at setup by supporter), the Settings app itself, all status-bar icons/indicators, notifications prompting updates, satellite SOS/auto-dial. Contact gating (anyone / all contacts / favorites) applies symmetric to calls and messages. All administration requires exiting the mode — the user inside AA cannot change anything.
